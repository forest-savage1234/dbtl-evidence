# v1.8 — realized process trajectories

## Scope

Retain bounded pH, dissolved oxygen or temperature CSVs with exact culture linkage, explicit time/value units, UTC origin and declared alignment. Versioned policies specify the observation window, maximum sampling gap and observed-point limits. Independent comparability assessments remain necessary. Endpoints must be observed exactly; this release does not interpolate.

## Challenges

Constant and oscillating synthetic trajectories share identical nominal context but yield different findings. Tests challenge missing sensors, unassessed clock/sensor mapping, gaps, absent endpoints, conflicting origins, minutes versus hours, repeated timestamps, nominal setpoints presented as observations, wrong units and corrupt sensor bytes.

## Limits

Passing checks says only that sampled points satisfy declared limits. It establishes neither behavior between points nor process equivalence, sensor accuracy, oxygen-transfer equivalence or industrial scale-up. Culture clock origin is asserted and needs external verification. No event alignment, feed mass balance, gas-transfer model or dynamic flux inference is implemented.
