# v2.0 — scoped decision packets and integrated reassessment

## Scope

Integrate assessed physical units, scoped genotype observations, assay/covariance evidence, observed process windows, bounded pools and separate literature references into one frozen packet. Unknown/conflicting requirements withhold ranking. Current packet state reconciles new candidates, review entities, mappings, availability and source/policy revisions. Historical replay reconstructs heads at the sealed registry watermark using exact recorded code/runtime. Explicit `advance` requires a current eligible packet and human rationale. CLI, static report, recovery and clean-source campaign are included.

## Challenges

Independent exact-rational and set oracles complement adversarial tests. Integration challenges cover omitted new candidates, new reviewer conflict, missing evidence, aliased cultures across strains, withdrawn readings after snapshot refresh, uncertain access, tampered/forged data, malformed contracts, calibration correction, one-way literature scope, unrelated-write stability and backup/restore. The gate runs the full suite and a retained synthetic campaign: A initially leads; newly registered C reopens the packet and leads after explicit reassessment; unknown source access reopens it again. Old packets still replay. Claim Review source is unchanged.

## Limits

This is version 2.0 of a local research instrument, not an industrial maturity claim or a complete solution to the original problem. Scientific support remains scoped reviewer assertion. No real laboratory/controlled comparative validation, producer authentication, guided scientist UI, live upstream discovery, LIMS/ELN integration, distributed storage or omics-scale qualification is completed. Genotype time horizon is fixed by explicit policy. First-order uncertainty is conditional and incomplete; descriptive ranks are not significance or robust-rank evidence. Legacy `freeze`/`decide` retain v1 semantics and do not enforce v2 packet gates. GitHub publication is pending repository availability/creation capability.
