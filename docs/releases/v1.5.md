# v1.5 — experimental units and duplicate observations

## Scope
Canonical declared physical cultures, aliquots and acquisitions; versioned
material mappings; explicit independence assessments; and duplicate source-row
rejection for quantity aggregation. Renamed entities do not create new culture
units when they map to the same declared physical culture.

## Challenges
Aliquot/culture aliases, unassessed barcodes, conflicting mappings, duplicated
acquisitions, reused CSV observations, canonical physical-ID collisions and
invalid hierarchies. Scoped support is distinct from physical authentication.

## Limits
The original v1 comparison remains a legacy descriptive calculation over declared
entity IDs. The new unit analysis must be used for the v2 decision packet. No
software can detect undisclosed physical aliases or prove independence from IDs.
