# v1.1 — independent evidence assessments

## Scope
Six independent assessment dimensions, exact evidence dependencies, conservative
conflict/staleness handling, and additive compatibility with storage schema 1.

## Challenges
Missing dimensions, unsupported status, evidence-free support, conflicting
reviewers, corrected sources, and reopening old state without rewriting records.
The full regression suite is the executable release gate.

## Limits
Support is a scoped reviewer assertion. No global verification flag, external
scientific adjudication or automatic execution of historical Python is provided.
Old datasets retain their source/runtime requirements; no schema rewrite is needed.
