# v1.7 — bounded assay evidence and conditional uncertainty

## Scope

Retain structured assay observations separately from measurement QC and reviewer assessment. The supported model is `concentration = dilution × (response − intercept) / slope`, converted to g/L. Four-variable covariance and eight-variable cross-measurement covariance are supplied explicitly. Exact rational algebra checks positive semidefiniteness and propagates first-order variance; decimal outputs use 50-digit half-even rounding.

## Challenges

An independent Fraction oracle checks a hand-derived variance. Shared calibration-intercept error cancels in a paired contrast; independent errors do not. Tests reject non-PSD/asymmetric/incomplete covariance, forged outputs and corrupt/ambiguous JSON. Proxy and censored readings cannot become quantified product concentration or zero.

## Limits

This does not fit or independently validate calibration, estimate missing covariance, establish metrological traceability or include every uncertainty source. Assay source observations and reviewer judgments can be wrong. The conditional model is first order, with no inferred confidence intervals, significance or biological causal inference. Matrix and calibration scope must match exactly. Real method-validation acceptance remains an external study gate.
