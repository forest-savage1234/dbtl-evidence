# v1.3 — evolving-pool decision reassessment

## Scope
Explicit watches bind a derived output to a bounded pool snapshot. Additions,
removals, changed eligibility, withdrawals, unavailable evidence and scope changes
create reproducible review requests. Reconciliation is derived from committed
history, so restart and rolled-back writes cannot lose notifications.

## Challenges
New independent evidence, irrelevant mismatches, withdrawals, access loss,
harmless bibliographic notices, stale review tokens, acknowledgement followed by
another change, restart and interrupted ingestion. The old snapshot remains replayable.

## Limits
Polling is explicit; no background file watcher or automatic decision is implied.
Acknowledging a request does not make old evidence current. Scope and availability
classifications are human declarations. Upstream completeness remains unknown.
