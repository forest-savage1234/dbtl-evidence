# Comparative field campaign — prepared, not executed

## Decision and baselines

Choose one permitted local acquisition-to-decision task with a participating laboratory: which strains merit human review for another experiment in one defined process. Freeze the analyte, assay, target environment, outcome, exclusions and evidence-access tier. Compare the lab's current workflow, a configured existing platform, and that same platform with this evidence layer. Include platform configuration, source mapping, curation, review and recovery time. Stop the standalone-product direction if an existing extension offers equivalent integrity with lower total burden.

## Corpus and independent adjudication

Screen at least twelve diverse permissible public cases as a coverage pilot, not an efficacy sample-size claim. Retain exact source versions and hashes, access limits and original experiment families. Include true positive controls and harmless changes alongside numerical errors, denominator ambiguity, missing pairs, aliases, proxy/direct differences, genotype scope, process histories, source revisions and new candidates. Missing public evidence stays unresolved; it is not a false-result label.

An independent analytical scientist and bioprocess/statistics reviewer define bounded expected assertions and unresolved questions before implementation sees holdouts. Resolve disagreements or retain disagreement; do not force consensus. Hash/freeze corpus, adjudication rules and analysis plan. Split by original experiment/lineage/batch/time to avoid reused-data leakage. Cases requiring unavailable licensed data cannot silently move into the usable subset.

## Evaluation

Use balanced task order and comparable training; blind adjudicators to workflow identity where feasible. Log consequential unsupported assertions, missed relevant changes, useful coverage, false alerts and total human time. Track withdrawals and exclusions in every denominator. Report case-family clustered uncertainty intervals; choose the actual study size after pilot variance and the minimum useful effect are agreed and preregistered. Do not manufacture a power calculation or commercial savings estimate from synthetic timings.

Every assertion promoted by software must map to a completed check and retained evidence. An unresolved requirement must survive JSON, human report, handoff and review. Zero observed consequential overclaims is necessary for the pilot but cannot prove a zero population error rate. Stop use of a failing profile, record the failure, repair it and retest a newly frozen holdout rather than relabeling the failed case.

## Laboratory and reliability gates

Replay one real permitted raw export through calibrated quantities, material identity, scoped genotype observation, process trajectory, comparison and explicit human decision. Inject a known source correction, new independent candidate, withdrawal, access loss and reviewer disagreement. Independently inspect exclusions and physical-unit mapping. Measure scientific review burden as well as software runtime.

Declare measured file sizes, ingestion/query mix, concurrent users, lineage depth and recovery objectives before load tests. Test restart during ingestion, rollback, duplicate delivery, corrupted/missing objects, unavailable source and restore to a fresh host. Qualify authentication, permissions, acquisition attestations, administrative controls and retention for the actual deployment. No hundreds-of-millions-row performance conclusion follows from the reference benchmark.

## Publication and stop criteria

Publish protocol, source-access ledger, failures, exclusions, adjudication disagreements, code/runtime identities and both benefit and burden estimates. Keep Claim Review and DBTL releases independent; any checker upgrade needs its own tests/release. Report a one-way receipt as such. Broad industrial validation remains uncompleted until a real partner, permissible data and independent review support the defined claim.
