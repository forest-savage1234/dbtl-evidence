The campaign to close the gap

  1. Freeze one laboratory decision, exact assay/process scope, error taxonomy and permitted sources. Screen at least twelve public cases as a coverage pilot; do not call it an efficacy sample.
  2. Use independent scientific adjudicators and experiment-family holdouts. Preserve unresolved evidence and disagreements.
  3. Compare the present workflow, a configured existing platform and that platform with this layer. Include setup, curation, false alerts, serious unsupported assertions, missed changes and review time.
  4. Replay a permitted real acquisition-to-decision chain; inject corrections, independent new candidates, access loss and recovery failures against predeclared objectives.
  5. Publish outcomes and limits. Stop the standalone-product direction if an existing extension gives equivalent integrity with less burden.

These external studies are prepared, not completed. No benefit estimate or industrial success is inferred from synthetic tests. The archive contains the full field protocol and an eighteen-work-package completion crosswalk.

Important operating limits

Reviewer support is asserted. Genotype calls are precomputed, scoped and tied to a fixed review horizon. First-order uncertainty is conditional on supplied covariance and omits unidentified effects. Observed process points do not establish behavior between samples or transfer across scale. Descriptive ranks are neither significance nor robust-rank evidence. Pools cover registered history, with polling rather than background discovery. Legacy freeze/decide commands retain v1 scope and do not enforce v2 packet gates.

Historical numerical replay requires the recorded code and exact runtime; archived code is never auto-executed. This release was tested with Python 3.12.14 and SQLite 3.53.1 on the recorded Linux environment.
